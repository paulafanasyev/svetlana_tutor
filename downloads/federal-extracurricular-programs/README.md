# Федеральные рабочие программы внеурочной деятельности

Официальный каталог: https://edsoo.ru/rabochie-programmy-vd/

GitHub Actions скачает прямые PDF-ссылки с домена edsoo.ru, проверит сигнатуру PDF и вычислит SHA-256, затем добавит карточки в общий индекс материалов.

Статус: первая автоматическая загрузка ещё не подтверждена. Точный класс и предмет нужно проверять по титульной странице. Наличие локальной копии не означает автоматически, что разрешено её дальнейшее распространение.
