# Окно КонсультантПлюс

Плагины `frp-noo-content.js` и `frp-extract.js` при сборке берут текст ФОП из КонсультантПлюс.
Документы открыты по расписанию: будни 20:00–24:00 МСК (00:00–04:00 по Сайгону), выходные весь день.

Вне окна сборка не падает, а пишет предупреждение «КонсультантПлюс вне расписания: 0 из N, остальное из корпуса»
и подставляет содержание и результаты из корпуса ЕДСОО. Такую сборку нужно повторить в окно.

Пересборка main: любой коммит в `apps/web/` или перезапуск последнего прогона Web CI во вкладке Actions в окно.
Проверка: в аннотации `c0` должно быть `n=93/93` без ошибок.
