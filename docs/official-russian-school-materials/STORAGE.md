# Где лежат школьные материалы

- **PDF не хранятся в git.** Они лежат в GitHub Release `school-materials-2026-10`: 55 ФРП (`frp-<id>.pdf`), 53 программы внеурочки (`vd-<12 hex>.pdf`), приказ № 436 (`fpu-436-2026.pdf`) и его текстовый слой (`fpu-436-2026.txt`).
- **Индексы и манифесты** лежат в `data/school-materials/`, вне `apps/web/src`, поэтому в бандл приложения не попадают. В манифестах (`data/school-materials/manifests/`) у каждого файла есть ссылка на первоисточник, sha256, размер и имя в релизе.
- **Обновление.** Запускается воркфлоу `School materials sync`: он срабатывает на push в ветки `materials/**` или вручную, в main не запускается. Бот коммитит только `data/school-materials/`, коммит с PDF или TXT он не делает.
- **`REPORT.md`** бот перегенерирует при каждом прогоне: схема данных, счётчики, сверка с `apps/web/src/data/fpu_status.json`.

## Статусы и ограничения

- **ФРП и внеурочка с ЕДСОО** помечены `provenance: corpus`: это копии из корпуса, с ФОП ред. 10.11.2025 они не сверялись.
- **Перечень учебников (ФПУ).** Источник правды для приложения: `apps/web/src/data/fpu_status.json` и `textbooks_add.json`.
  - `federal-textbook-bibliography-2026-full-extraction.json` сделан OCR, в нём есть опечатки и обрезанные названия. Это черновик (`OCR_EXTRACTED_NEEDS_RECHECK`).
  - `federal-textbooks-2026-*.json` собраны с garant.ru и содержат срок «До 31 августа ГГГГ».
- **Коды позиций в приказе № 436 повторяются в разных таблицах.** Например, 1.1.1.7.1.1 это Информатика № 110 в одной таблице и Окружающий мир № 199 в другой. Учебник однозначно определяет только пара «номер + код».
- **Текстовый слой PDF приказа почти пустой** (около 8 тыс. символов на 312 страниц), без OCR искать по нему нельзя.
- **Резервная копия** исходной загрузки осталась в ветке `feat/official-russian-school-materials`.
