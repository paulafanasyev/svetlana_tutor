**Рабочая ветка:** `feat/official-russian-school-materials`  
**Дата расширения:** 21 октября 2026 г.  
**Охват:** классы 1–11, предметы начальной, основной и средней школы.

## Состав каталога

- `apps/web/src/data/official-russian-school-material-items.json` — индекс конкретных открытых ресурсов, материалов ФИПИ и открытых справочных страниц.

- `apps/web/src/data/historical-school-textbooks-library.json` — библиографические записи найденных страниц исторической библиотеки школьных учебников РАО.

- `apps/web/src/data/school-curriculum-coverage.json` — матрица по классам и предметам с явным статусом полноты.

Общий индекс материалов содержит найденные страницы разделов ФПУ и исторические библиографические записи. Этот общий индекс не является утверждением, что все учебники загружены локально.

## Реальные файлы учебников и условия прав

Цель — максимально полная учебная библиотека, но каждый материал должен иметь один из статусов:
- `LOCAL_OPEN_LICENSE`: файл помещён в репозиторий, лицензия и атрибуция приложены.
- `LOCAL_PUBLIC_DOMAIN`: файл помещён после обоснования статуса общественного достояния.
- `OFFICIAL_DOCUMENT`: официальный нормативный/правительственный документ, сохранён с реквизитами первоисточника.
- `LINK_ONLY`: доступен через издателя или платформу; права на копирование не подтверждены.
- `NOT_PROVEN`: нет достаточных данных о полноте, доступности или праве перераспространения.

Наличие книги в федеральном перечне, возможность её посмотреть в интернете или формулировка «для образовательного использования» сами по себе не дают разрешения включить её целиком в публичный GitHub-репозиторий. Для коммерческих учебников нужно использовать лицензионный файл или официальную ссылку.

## Что означает «все учебники»

Полный перечень и библиографические записи — не то же самое, что полные тексты всех книг. Федеральный перечень содержит сведения об изданиях, но не включает сами учебники как отдельные PDF. Коммерческие учебники издательств не зеркалируются без подтверждённого разрешения; для них сохраняются записи и официальные ссылки. Поэтому **наличие всех полных текстов всех учебников в ветке остаётся NOT PROVEN**.

Новые материалы синхронизируются только с официальных страниц ЕДСОО/Минюста; автоматическая загрузка ограничена PDF с официального домена, а для каждого сохранённого файла ведутся источник, статус и контрольная сумма. Ошибки доступа не маскируются: их нужно исправлять отдельно, не маркируя несуществующие файлы как скачанные.
