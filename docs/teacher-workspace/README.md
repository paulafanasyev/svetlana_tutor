# Рабочее место учителя: школьные программы, документы и отчётность

## Что реализовано

- Шаблоны: план урока, КТП, отчёт о выполнении рабочей программы, отчёт по предмету, аналитический отчёт по классу, сводка по заданиям и сдаче работ из локального модуля, анализ контрольной работы, план коррекционной работы, индивидуальный план поддержки, сообщение родителям, протокол родительского собрания, план классного часа, педагогическая характеристика, объяснительная записка, самоанализ и рабочий лист с отдельным блоком ключа учителя.
- Редактирование готового текста, локальные черновики, экспорт Markdown и HTML для печати/сохранения в PDF.
- Расчёт успеваемости и качества только при вводе четырёх числовых показателей.
- Обезличенная сводка по заданиям «Классы и чат»: ответы, доля сдачи, оценки, выставленные учителем, и средняя отметка по этим работам. Не подменяет электронный журнал и не считает посещаемость. При неполных или противоречивых данных показатели не подставляются.
- Отдельный отчёт по существующему электронному журналу через `api.myClasses()` и `api.listJournal()`: фильтр периода, количество и типы записей, распределение итоговых отметок, средняя отметка и показатели по оценённым записям. Имена, комментарии и идентификаторы не экспортируются. В `DemoApi` это демонстрационные данные в браузере; официальный отчёт требует проверки источника и подключения реального серверного API.
- В рабочем месте можно выбрать программу по классу и предмету, подтянуть разделы/темы/результаты из локального каталога ФОП/ФРП и сформировать черновик КТП. Список тем ограничен плановым числом часов и допускает ручную корректировку; календарные даты и реальные проведённые часы не выдумываются.
- Рабочее место показывает проверенную дату матрицы покрытия и показатели выбранной пары «класс × предмет»: наличие записей в индексах, записей ФРП, PDF в релизе и авторских заданий. Полнота из матрицы не подменяется уверенностью модели: статус `NOT_PROVEN` отображается явно. Индексные записи не равны числу уникальных учебников.
- Отчёт о выполнении программы сравнивает плановые и фактические часы только по явным значениям, введённым учителем.
- При переходе из рабочего места в ИИ-чат черновик передаётся для редактуры. Чат по возможности подбирает релевантную программу из локального каталога ФОП/ФРП по предмету и классу.
- Источники нормативных и учебных сведений перечислены внутри справочного контекста; приложение должно показывать пробелы, а не придумывать отсутствующую программу.

## Источники для перепроверки

- Приказ Минпросвещения России от 06.11.2024 № 779: https://publication.pravo.gov.ru/document/0001202412050007
- Единое содержание общего образования — федеральные рабочие программы: https://edsoo.ru/rabochie-programmy/
- Федеральный перечень учебников 2026 года, приказ № 436: https://publication.pravo.gov.ru/document/0001202607230005
- ФИПИ — материалы ГИА: https://fipi.ru/
- Разъяснения Минпросвещения от 16.09.2026 № 03-1772 (справочная публикация): https://base.garant.ru/414943108/

Приказ № 779 вступил в силу 1 марта 2025 года. Его применимость зависит от раздела перечня, должности и уровня образования. Нельзя представлять все шаблоны этого модуля как обязательные документы для каждого школьного учителя. Проверяйте действующий текст и локальные акты организации.

## Достоверность и ограничения

- Шаблон — только начальная структура, а не подписанный или утверждённый документ.
- Расчёт процентов использует только явно введённые числа и не объясняет причины успеваемости.
- Каталог программ содержит отметки о происхождении содержания и результатов. Фрагмент из корпуса/непроверенного источника нельзя выдавать за дословно сверенную ФОП.
- Текущая версия сохраняет черновики в localStorage без шифрования, на одном браузере/устройстве. Не использовать на общедоступном устройстве для полной персональной карточки ученика. Данные не отправляются в школьную электронную систему.
- Сгенерированные файлы не подают документы в школу автоматически. Перед передачей проверьте факты, адресатов, подписи, локальные формы, сроки и допустимость включения персональных данных.

## Архив и история версий (обновлено 25.10.2026)

- Резервная копия библиотеки сохраняется в локальный JSON-файл; архив включает черновики, формы и до пяти предыдущих версий каждого документа.
- Библиотека поддерживает поиск по названию, тексту, предмету, классу и другим текстовым полям формы; поиск работает локально по уже сохранённым черновикам.
- Импорт проверяет формат и номер версии архива, тип документа, размер файла/текста и структуру полей. Импортированные записи не перезаписывают уже сохранённые черновики: совпадающие ID получают новый локальный ID.
- В браузере остаётся максимум 30 черновиков. При нехватке места в списке импорт показывает число пропущенных записей и сохраняет уже существующие документы; исходный JSON нужно хранить до успешного переноса оставшихся записей.
- Предыдущую версию можно открыть из истории и затем сохранить как новую текущую редакцию. В истории хранится не более пяти снимков на документ.
- JSON-архив не зашифрован. Не включайте в него избыточные персональные данные учащихся и храните резервную копию в защищённом месте. Это локальное резервное копирование, а не серверная синхронизация, резервирование на сервере или система разграничения доступа.

Результаты проверки покрытия по снимку исходных JSON от 21–22.10.2026 сохранены в [CURRICULUM-COVERAGE-AUDIT-2026-10-25.md](./CURRICULUM-COVERAGE-AUDIT-2026-10-25.md). Весь каталог остаётся NOT PROVEN по полноте; запись или ссылка на программу не означает проверку её полного содержимого.

## Проверка доступности источников программ

- Workflow `.github/workflows/federal-program-link-audit.yml` запускает отдельную периодическую/ручную проверку официальных ссылок и файлов релиза.
- Запуск: `node scripts/audit-federal-program-links.mjs`; необязательные аргументы `--input=path`, `--output=path`, `--timeout-ms=12000`.
- Скрипт ограничен HTTPS-доменами `edsoo.ru`, `fgosreestr.edsoo.ru` и `github.com`; проверяет HTTP-ответ, а для PDF — первые байты с Range-запросом и сигнатуру `%PDF-`. Тело ответа отменяется после первого фрагмента.
- Отчёт сохраняется как JSON-артефакт GitHub Actions на 90 дней. Недоступные ссылки отражаются в отчёте, но не блокируют релиз: временный сетевой сбой не должен превращаться в ложное утверждение об отсутствии программы.
- Успешный HTTP/PDF-чек **не** подтверждает полноту программы, редакцию документа, корректность OCR, соответствие федеральным требованиям или школьному учебному плану. Для повышения статуса требуется отдельная предметная сверка.
- Инженерное состояние защиты и хранения данных описано в [SECURITY-AND-DATA-RETENTION.md](./SECURITY-AND-DATA-RETENTION.md). Серверная синхронизация, серверное шифрование, политика сроков хранения и правовая оценка — отдельные невыполненные задачи.
