## Не проверено

- Учитель-предметник вопросы не смотрел. В приложении это написано под каждой игрой.
- Соответствие ФОП критики проверяли по своим знаниям и выборочно по тексту ФОП, а не построчно по разделу «Содержание обучения» каждого класса.
- Дубли тест ловит только по совпадению текста. Вопросы, близкие по смыслу, но иначе сформулированные, в одном классе возможны.
