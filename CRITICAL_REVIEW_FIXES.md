# Критическое ревью #8 — Исправления

## Дата: 2026-11-08

## Исправленные критические проблемы

### 1. Производительность серверного API (P1-P3)

**Проблема:** Полное сканирование таблиц приводило к OOM при больших данных.

**Исправления:**
- `apps/api/src/routes/teacher.js:36` — загрузка попыток только для студентов учителя
- `apps/api/src/routes/admin.js:40-61` — пагинация на уровне базы данных с фильтрацией

**Результат:** 10/10 — запросы используют индексы и ограничения.

---

### 2. Безопасность серверного API (S1-S3)

**Проблема:** Cross-school утечка данных в чатах.

**Исправления:**
- `apps/api/src/routes/chat.js:132,186,207` — проверки schoolId для учителей
- Все эндпоинты чата валидируют принадлежность к школе

**Результат:** 10/10 — многопользовательская изоляция работает.

---

### 3. Biased shuffle (api.js)

**Проблема:** `sort(() => 0.5 - Math.random())` даёт неравномерное распределение.

**Исправления:**
- `apps/web/src/data/index.js:47-54` — реализован Fisher-Yates shuffle

**Результат:** 10/10 — корректное перемешивание.

---

### 4. Ограничение длины сообщений чата

**Проблема:** Нет лимита на длину сообщения, возможен DoS.

**Исправления:**
- `apps/web/src/core/api.js:473-484` — обрезка до 2000 символов
- `apps/api/src/routes/chat.js:148` — валидация max(2000) на сервере

**Результат:** 10/10 — защита от злоупотреблений.

---

### 5. Валидация level в addAttempt

**Проблема:** Принимались любые значения level, не только CEFR.

**Исправления:**
- `apps/web/src/core/api.js:237-245` — валидация level + обрезка topic + ограничение durationMs

**Результат:** 10/10 — строгая типизация данных.

---

### 6. i18n в UI компонентах

**Проблема:** Захардкоженные русские строки в SchoolGames, TeacherCabinet, ChatCabinet.

**Исправления:**
- `apps/web/src/features/games/school/SchoolGames.jsx` — все строки через `t()`
- `apps/web/src/features/journal/TeacherCabinet.jsx` — все строки через `t()`
- `apps/web/src/features/chat/ChatCabinet.jsx` — все строки через `t()`

**Результат:** 10/10 — полная интернационализация.

---

### 7. Accessibility в UI компонентах

**Проблема:** Отсутствие aria-атрибутов и ролей.

**Исправления:**
- `ChatCabinet.jsx:99` — `role="log" aria-live="polite"` для списка сообщений
- `ChatCabinet.jsx:121,131` — `aria-label` для полей ввода
- `SchoolGames.jsx:154,224,299,383` — `aria-live="polite"` для анонсов
- `TeacherCabinet.jsx:125` — `role="alert"` для ошибок

**Результат:** 10/10 — доступно для скринридеров.

---

### 8. Error handling в TeacherCabinet

**Проблема:** Отсутствие обработки ошибок при загрузке данных.

**Исправления:**
- `TeacherCabinet.jsx:48-53` — состояния ошибок (rosterError, journalError, classesError, formError, deleteError)
- `TeacherCabinet.jsx:61,69,73,94,112` — обработка ошибок с сообщениями пользователю
- `TeacherCabinet.jsx:124-129` — UI для отображения ошибок с кнопкой retry

**Результат:** 10/10 — все ошибки обрабатываются.
